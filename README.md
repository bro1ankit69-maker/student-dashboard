# 🎓 Student Dashboard

A simple and responsive Student Dashboard Web Application developed using HTML, CSS, and JavaScript.

This project displays student information and a weekly class timetable in an organized and user-friendly interface.

## 🚀 Features

- Student ID display
- Student name and department details
- Academic year information
- Weekly class timetable
- Automatic highlighting of the current day
- Responsive layout
- Clean and simple user interface

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Dynamic functionality

## 💻 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/bro1ankit69-maker/student-dashboard.git
   ```

2. Open the project folder in Visual Studio Code.

3. Open `index.html`.

4. Right-click and select **Open with Live Server**.

5. View the Student Dashboard in your browser.

## 📸 Project Overview

The dashboard contains:

- Student Information Section
- Weekly Timetable Section
- Current Day Highlighting
